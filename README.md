# 图片归档工作台

这是图片归档与生产状态管理系统的产品设计资料目录。

## 文件说明

- `PRD.md`：产品需求文档，描述业务目标、范围、流程、页面、规则和验收标准。
- `technical-design.md`：技术设计草案，描述模块划分、数据表、接口、导入流程和校验规则。
- `implementation-plan.md`：MVP 实施计划，按阶段拆解开发任务和验收标准。
- `prototype/index.html`：可打开的静态 UI 原型。
- `prototype/screenshots/`：原型截图。

## 建议阅读顺序

1. 先看 `PRD.md`，确认产品逻辑。
2. 再看 `prototype/index.html`，对照页面结构。
3. 然后看 `technical-design.md`，确认技术边界。
4. 最后看 `implementation-plan.md`，进入排期和开发拆分。

## 当前 MVP 范围

- 登录。
- 图片归档入口。
- Excel 导入。
- 手动上传。
- 图片中心。
- 主图详情。
- 套图管理。
- 状态看板。
- 操作日志。

## 当前图片类型

- 手提包。
- 单肩背包。
